# dioxus-registry-preview-core

[![crates.io](https://img.shields.io/crates/v/dioxus-registry-preview-core?label=crates.io&style=flat-square)](https://crates.io/crates/dioxus-registry-preview-core)
[![docs.rs](https://img.shields.io/docsrs/dioxus-registry-preview-core?label=docs.rs&style=flat-square)](https://docs.rs/dioxus-registry-preview-core)

Dioxus-free discovery, validation, Markdown rendering, and catalog models for component Registry Previews.

Consumers should use [`dioxus-registry-preview`](https://github.com/sagikazarmark/dioxus-registry-docs/tree/main/crates/dioxus-registry-preview), which re-exports the stable validation interface.

This supporting package contains the ordinary Rust model used by validation and macro expansion.
It has no Dioxus dependency and is released in lockstep with the facade.
